# Shorts — Per-Short Asset Packages

Each Short = vertical cover (thumbnail) + voiceover (audio) + two clips (video) + title + description.
All assets live in your Higgsfield account; IDs below map to `shorts_assemble.sh` filenames.
Build: two clips → concat → lay VO on top → burn in captions → export 1080×1920.
